> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Goal: TypeScriptのPlaywrightをe2e/playwrightに構築し、ログイン、初回セットアップ、購読追加、既読化、本文オーバーレイ表示、テーマ切替などの主要フローをブラウザで検証します。scripts/verify-hardening.shをSSRF拒否と初回セットアップ無効化とCSRF検証のシナリオで拡張します。.github/workflows/ci.ymlにPlaywrightのe2eジョブを追加してレポートをartifactとしてアップロードします。

Architecture: Playwrightは実際に起動したfeedflowバイナリへHTTP接続して操作します。テスト専用の隔離データディレクトリを毎回作り直し、各specは初回セットアップでユーザーを作ってからログインする独立したフローで動きます。scryptのコストとレートリミットはテスト用の環境変数で緩めます。verify-hardening.shはGoのhttptest相当をGoのテストバイナリ経由ではなく、起動済みサーバへのcurl相当の検証をbashとgoのインラインプログラムで行い、固有ホストや個人パスへ依存しません。CIはPhase0で作ったpre-commitジョブと並列に、Goビルド成果物を使うe2eジョブを追加します。

Tech Stack: Playwright(TypeScript)の1.49系とNode.js 24と@playwright/testを使い、Go 1.25でビルドしたfeedflowバイナリへ接続し、bashとgoのインラインプログラムで検証します。

## Task 0: 前提となるルートとUI契約の確認

このPhaseのテストが依存するハンドラのルートとUIの目印を、Phase7のrouter.goと実テンプレートの確定実装に合わせて次のとおり固定します。後続のすべてのstepはこの契約を前提にします。Phase7の実装が正であり、specのパスとセレクタはこの実装へ読み替え済みです。

ルート契約です。Phase7のrouter.goが登録するパスとメソッドに一致します。

| メソッドとパス | 役割 | 認証 | 主要レスポンス |
| --- | --- | --- | --- |
| `GET /healthz` | 死活監視 | 不要 | 本文`ok` |
| `GET /setup` | 初回セットアップ画面 | 不要(未登録時のみ到達可) | フォーム`form.auth-form` |
| `POST /setup` | 初回セットアップ登録 | 不要(未登録時のみ) | 登録後`/login`へ303 |
| `GET /login` | ログイン画面 | 不要(未登録時は`/setup`へ303) | フォーム`form.auth-form` |
| `POST /login` | ログイン実行 | 不要 | 成功時`/app`へ303 |
| `POST /logout` | ログアウト | 要 | `/login`へ303 |
| `GET /app` | メイン2ペイン画面 | 要(未認証は`/login`へ303) | `.app-shell` |
| `POST /app/feeds` | 購読追加 | 要(CSRF) | HTMX部分更新`#tree-pane` |
| `GET /app/items?feed=<id>` | 記事リスト | 要 | HTMX部分`.item-list` |
| `POST /app/items/{feedID}/{itemID}/read` | 既読既読解除 | 要(CSRF) | HTMX部分更新`#item-<id>` |
| `POST /app/items/markall` | 全既読 | 要(CSRF) | HTMX部分更新`#main-pane` |
| `GET /app/items/{feedID}/{itemID}` | 本文オーバーレイ | 要 | HTMX部分`#reading-overlay`の中身 |

テーマ切替はサーバ側に永続化ルートを持ちません。設計書のセクション11のとおり、テーマの切替と永続化はAlpine.jsが担い、`localStorage`へ保存します。E2Eはこのクライアント保存の挙動を検証します。

UIの目印です。Phase7の実テンプレートのクラス名と属性に一致します。

- 状態変更系のPOSTはbaseのbodyに付いた`hx-headers`の`X-CSRF-Token`でトークンを送ります。authフォームとは別経路のため、setupとloginのフォームには`csrf_token`の隠しフィールドはありません
- 初回セットアップフォームは`form.auth-form`、入力は`input[name="username"]`と`input[name="password"]`です
- ログインフォームは`form.auth-form`、入力は`input[name="username"]`と`input[name="password"]`です
- メイン画面の最上位ラッパは`.app-shell`です。テーマは`<html>`要素の`data-theme`属性で表し、テーマ切替ボタンはアプリバーの`button.icon-btn[aria-label="テーマ切替"]`です。Alpineの`init`で保存値があれば`data-theme`を適用し、`toggleTheme`で`dark`と`light`を入れ替えて`localStorage`へ保存します
- ログアウトはアプリバーの`form[action="/logout"]`内の`button.icon-btn`です
- 購読ツリーは`#tree-pane`、購読追加フォームは`form.subscribe-form`で`input[name="url"]`を持ちます
- 記事リストは`.item-list`、各記事は`li.item-card[data-feed][data-item]`で`id="item-<id>"`を持ちます。既読は`is-read`クラスで表します
- 既読ボタンは各記事内の`.item-quick button.quick-btn`です。全既読ボタンは`.item-list-bar form[action="/app/items/markall"]`内の`button.btn-ghost`です
- 記事タイトルは`a.item-open`内の`h3.item-title`です。`a.item-open`をクリックすると本文オーバーレイ`#reading-overlay`が`x-show`で開き、本文は`.reading-body`に入ります
- オーバーレイの閉じるボタンはオーバーレイ内の`button.icon-btn[aria-label="閉じる"]`です。Escキーでも閉じます

環境変数の契約です。Phase8のloadConfigが読む変数だけを使います。

- `FEEDFLOW_ADDR` 待受アドレス
- `FEEDFLOW_DATA_DIR` JSON永続化ディレクトリ
- `FEEDFLOW_BASE_URL` 公開ベースURL
- `FEEDFLOW_SESSION_KEY` セッション署名鍵

scryptのコストとログインのレート上限を緩める環境変数knobは、Phase8のConfigには含まれません。E2Eとverify-hardeningはこれらに依存せず、本番既定のままで動かします。テストごとにデータディレクトリを作り直すため、scryptの計算回数は1ユーザーの登録とログインに限られ、実用上の遅さにはなりません。

セッションCookieのSecure属性は`FEEDFLOW_BASE_URL`のスキームに従い、E2EとverifyがhttpのベースURLを渡すため平文接続でもセッションが維持される前提です。Phase7のauthがベースURLのスキームからSecureを決めるため、専用の環境変数は使いません。

このPhaseは、Phase7のbuildHandlerが実依存(store、feed、service、poller、auth)を結線済みでハンドラを返すことを前提にします。Phase7の完了条件にこの結線が含まれるため、E2Eとverifyはそのバイナリをそのままビルドできることを前提に進めます。buildHandlerが空のDepsを返す段階では、起動時に未結線で失敗します。その場合はPhase7の結線タスクの完了を待ってから本Phaseを実行します。

この契約に沿って以降を実装します。コードを書くstepはありません。

import { AddressInfo } from "node:net";
import { Page, expect } from "@playwright/test";

// USERNAME はE2Eで登録するユーザー名です。
export const USERNAME = "owner";
// PASSWORD はE2Eで登録するパスワードです。
export const PASSWORD = "correct-horse-battery-staple";

// SAMPLE_RSS はテスト用フィードサーバが返すRSS2.0の本文です。
export const SAMPLE_RSS = `<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0">
  <channel>
    <title>E2E Sample Feed</title>
    <link>http://example.test/site</link>
    <description>feedflow e2e sample</description>
    <item>
      <title>First E2E Article</title>
      <link>http://example.test/articles/1</link>
      <guid>http://example.test/articles/1</guid>
      <description>Body of the first article for e2e.</description>

    </item>
    <item>
      <title>Second E2E Article</title>
      <link>http://example.test/articles/2</link>
      <guid>http://example.test/articles/2</guid>
      <description>Body of the second article for e2e.</description>
      <pubDate>Mon, 26 May 2026 10:00:00 +0900</pubDate>
    </item>
  </channel>
</rss>`;

// startFeedServer はテスト用のフィード配信HTTPサーバを起動してURLを返します。
export async function startFeedServer(): Promise<{ url: string; close: () => Promise<void> }> {
  const server: Server = createServer((req, res) => {
    if (req.url === "/feed.xml") {
      res.writeHead(200, { "Content-Type": "application/rss+xml; charset=utf-8" });
      res.end(SAMPLE_RSS);
      return;
    }
    res.writeHead(404, { "Content-Type": "text/plain" });
    res.end("not found");
  });
  await new Promise<void>((resolve) => server.listen(0, "127.0.0.1", resolve));
  const addr = server.address() as AddressInfo;
  const url = `http://127.0.0.1:${addr.port}/feed.xml`;
  const close = () =>
    new Promise<void>((resolve, reject) =>
      server.close((err) => (err ? reject(err) : resolve())),
    );
  return { url, close };
}

test.describe("認証と初回セットアップ", () => {
  test("未認証でメイン画面へアクセスするとログインへ誘導される", async ({ page }) => {

    await page.fill('form.auth-form input[name="password"]', "wrong-password");

  });

  test("登録後は初回セットアップ画面へ到達できずログインへ送られる", async ({ page }) => {
    await completeSetup(page);
    await page.goto("/setup");
    await expect(page).toHaveURL(/\/login$/);
    await expect(page.locator("form.auth-form input[name='password'][minlength='8']")).toHaveCount(0);
  });

  test("ログイン後にログアウトすると再びログインが必要になる", async ({ page }) => {
    await completeSetup(page);
    await login(page);
    await page.click('form[action="/logout"] button[type="submit"]');
    await expect(page).toHaveURL(/\/login$/);
    await page.goto("/app");
    await expect(page).toHaveURL(/\/login$/);
  });

package main

	"context"
	"fmt"
	"os"

	"github.com/okamyuji/feedflow-go-htmx/internal/port"

func main() {

		feed.WithTimeout(5*time.Second),
		feed.WithMaxBytes(1<<20),
	)
	loopback := []string{
		"http://127.0.0.1:9/feed.xml",
		"http://localhost:9/feed.xml",
		"http://169.254.169.254/latest/meta-data/",
		"http://10.0.0.1/feed.xml",
		"ftp://example.test/feed.xml",
	}
	for _, u := range loopback {
		_, err := f.Fetch(context.Background(), port.FetchRequest{URL: u})

package main

import (
	"fmt"
	"net/http"
	"net/http/cookiejar"
	"net/url"
	"os"
	"regexp"
	"time"
)

var csrfRe = regexp.MustCompile(`name="csrf_token"\s+value="([^"]+)"`)

func extractCSRF(client *http.Client, target string) (string, error) {
	resp, err := client.Get(target)
	if err != nil {
		return "", err
	}
	defer func() { _ = resp.Body.Close() }()
	buf := make([]byte, 1<<20)
	n, _ := resp.Body.Read(buf)
	m := csrfRe.FindSubmatch(buf[:n])
	if m == nil {
		return "", fmt.Errorf("csrf_token not found in %s", target)
	}
	return string(m[1]), nil
}

func main() {
	base := os.Args[1]
	jar, _ := cookiejar.New(nil)
	client := &http.Client{
		Timeout: 5 * time.Second,
		Jar:     jar,
		CheckRedirect: func(*http.Request, []*http.Request) error {
			return http.ErrUseLastResponse
		},
	}

	// 初回セットアップでユーザーを登録する。
	reg := url.Values{}
	reg.Set("username", "owner")
	reg.Set("password", "correct-horse-battery-staple")
	if t, err := extractCSRF(client, base+"/setup"); err == nil {
		reg.Set("csrf_token", t)
	}
	respReg, err := client.PostForm(base+"/setup", reg)
	if err != nil {
		fmt.Fprintf(os.Stderr, "setup failed: %v\n", err)
		os.Exit(1)
	}
	_ = respReg.Body.Close()

	// ログインする。ログインPOSTはrequireCSRFの対象外のため、
	// ログイン画面にCSRFの隠しフィールドがあるときだけ付与する。
	loginForm := url.Values{}
	loginForm.Set("username", "owner")
	loginForm.Set("password", "correct-horse-battery-staple")
	if t, err := extractCSRF(client, base+"/login"); err == nil {
		loginForm.Set("csrf_token", t)
	}
	respLogin, err := client.PostForm(base+"/login", loginForm)
	if err != nil {
		fmt.Fprintf(os.Stderr, "login failed: %v\n", err)
		os.Exit(1)
	}
	_ = respLogin.Body.Close()
	if respLogin.StatusCode != http.StatusSeeOther && respLogin.StatusCode != http.StatusOK {
		fmt.Fprintf(os.Stderr, "login want 303 or 200 got %d\n", respLogin.StatusCode)
		os.Exit(1)
	}

	// CSRFトークン無しのPOST /app/feedsは拒否される(403)。
	noTok := url.Values{}
	noTok.Set("url", "http://127.0.0.1:9/feed.xml")
	respNo, err := client.PostForm(base+"/app/feeds", noTok)
	if err != nil {
		fmt.Fprintf(os.Stderr, "post feeds no-token failed: %v\n", err)
		os.Exit(1)
	}
	_ = respNo.Body.Close()
	if respNo.StatusCode != http.StatusForbidden {
		fmt.Fprintf(os.Stderr, "POST /app/feeds without token want 403 got %d\n", respNo.StatusCode)
		os.Exit(1)
	}

	// 正しいトークン付きのPOST /app/feedsはCSRFでは拒否されない。
	// 不正なurlのため取得自体は失敗しうるが、403でないことを確認する。
	pageTok, err := extractCSRF(client, base+"/app")
	if err != nil {
		fmt.Fprintf(os.Stderr, "page csrf failed: %v\n", err)
		os.Exit(1)
	}
	withTok := url.Values{}
	withTok.Set("url", "http://127.0.0.1:9/feed.xml")
	withTok.Set("csrf_token", pageTok)
	respYes, err := client.PostForm(base+"/app/feeds", withTok)
	if err != nil {
		fmt.Fprintf(os.Stderr, "post feeds with-token failed: %v\n", err)
		os.Exit(1)
	}
	_ = respYes.Body.Close()
	if respYes.StatusCode == http.StatusForbidden {
		fmt.Fprintln(os.Stderr, "POST /app/feeds with valid token unexpectedly 403")
		os.Exit(1)
	}

	fmt.Println("CSRF enforced for state-changing POST")
}
